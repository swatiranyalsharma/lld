## Getting Started

Welcome to the Java development workspace in Visual Studio Code. This repository is used to practice Java programming, object-oriented design, and common design patterns.

## Folder Structure

The workspace uses the following folders:

- `src/` — Java source code.
- `lib/` — External libraries and dependencies.
- `bin/` — Compiled Java class files generated by default.

To customize the folder structure or output directory, open `.vscode/settings.json` and update the relevant settings.

## Dependency Management

Use the **JAVA PROJECTS** view in VS Code to manage Java projects and dependencies.

For more information, see the [VS Code Java Dependency Manager documentation](https://github.com/microsoft/vscode-java-dependency#manage-dependencies).

## Topics Covered

- Object-Oriented Programming (OOP)
- SOLID Principles
- Creational Design Patterns
- Structural Design Patterns
- Behavioral Design Patterns
- Low-Level Design problems and implementations

## Running Java Programs

1. Open a Java file inside `src/`.
2. Ensure the Java extensions and JDK are installed in VS Code.
3. Click **Run** above the `main()` method.
4. View the output in the terminal.

Happy coding!
